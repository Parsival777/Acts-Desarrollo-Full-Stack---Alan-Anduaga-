# API de Tareas con Node.js y Express

Este proyecto es el cerebro o la parte trasera (backend) de una aplicación para gestionar tareas. Está creado con Node.js y Express, y en lugar de usar una base de datos compleja, guarda toda la información directamente en un archivo de texto llamado `tareas.json` para mantener las cosas súper simples. Además, cuenta con un sistema de seguridad basado en Tokens (JWT) para asegurar que solo los usuarios registrados puedan ver, crear o borrar información.

Para hacer que este código funcione en tu computadora, primero necesitas asegurarte de tener Node.js instalado. Una vez que descargues esta carpeta, abre tu terminal ahí mismo y escribe el comando `npm install` para que se descarguen las herramientas necesarias de forma automática. Cuando termine la instalación, simplemente escribe el comando `node server.js` y presiona Enter. Si todo sale bien, verás un mensaje avisando que el servidor está corriendo en el puerto 3000, lo que significa que el proyecto ya está encendido y listo para trabajar.

Como este programa no tiene una página web visual con botones, necesitas usar una herramienta como Thunder Client (en Visual Studio Code) o Postman para enviarle instrucciones. El primer paso es registrar tu usuario enviando una petición tipo POST a la dirección `http://localhost:3000/register` con tu nombre y contraseña en el cuerpo (Body) usando formato JSON. Una vez registrado, haces lo mismo pero hacia la dirección `/login` para iniciar sesión. Al hacer esto, el servidor te devolverá un código larguísimo llamado Token, que funcionará como tu llave de acceso.

Copia ese Token con mucho cuidado porque lo vas a necesitar para interactuar con tus tareas. Para poder crear, leer, actualizar o borrar cosas en la ruta `http://localhost:3000/tareas`, tienes que ir a la sección de "Headers" en tu programa de pruebas, agregar una fila que se llame `authorization` y pegar tu Token ahí. Con esa llave colocada correctamente, ya tienes permiso para usar los métodos GET, POST, PUT y DELETE, y podrás ver cómo el archivo `tareas.json` se actualiza completamente solo cada vez que agregas o quitas algo.
